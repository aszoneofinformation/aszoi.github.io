Project Development Guidelines

Guidelines governing the proposal, development, evaluation and documentation of ASZOI projects.

Version 1.0 · 29 August 2026
01 — Overview

About this document

This document establishes the general framework used by ASZOI for developing institutional projects.

It defines the basic stages through which a project may move, from initial proposal and classification through development, evaluation, completion and documentation.

02 — Purpose

Purpose and scope

The purpose of this guideline is to provide a consistent framework for developing projects while allowing individual projects to adapt their methods to their specific objectives.

The guideline applies to ASZOI projects where formal project documentation is appropriate.
